#EM QUE MOMENTOS DEVEMOS USAR PANDAS/PYTHON, SQL OU SPARK 
----------------------------------------------------------------------------------------------------------------------------

PYTHON = Quando precisar limpar, tratar e manipular os dados de uma forma flexivel. Linha a linha, coluna por coluna

SQL = Quando preciso de uma consulta, filtrar, agregar dados de uma maneira facil e declarativas. De uma forma que responda perguntas relacionadas ao negócio

SPARK = Quando o volume de dados é maior que a memória de uma máquina. Precisando processar em pararelo, distribuir em vários computadores
